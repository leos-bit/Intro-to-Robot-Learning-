Project Overview

This project studies autonomous drone navigation in cluttered environments using reinforcement learning. The agent must reach a goal while avoiding collisions and controlling effort.

  • Simulator: MuJoCo
  • Platform: Skydio X2-style quadrotor
  • Methods: PPO, SAC, and random baseline
  • Evaluation: Return, collisions, success rate

Reproducibility

Minimal startup flow for the MuJoCo reinforcement-learning setup:

cd mujoco_drone_imp
$env:PYTHONPATH = (Get-Location).Path
python -m drone_training.src.training.train_ppo
python -m drone_training.src.training.train_sac
