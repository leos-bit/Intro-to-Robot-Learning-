Project Overview

This project studies robust drone navigation in cluttered environments under wind disturbances. The agent must reach a goal while avoiding collisions and controlling effort.

  • Simulator: Gazebo Sim
  • Platform: Quadrotor model in SDF
  • Baseline: Random policy
  • Evaluation: Return, collisions, success rate

Environment Setup

Key files currently used in this repository:

  • quad_world.sdf - world configuration
  • quad_model.sdf - quadrotor model and plugins
  • random_policy.py - random action baseline
