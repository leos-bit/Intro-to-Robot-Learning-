Drone Pathing using Reinforcement Learning

Leo Shaw and Siddarth Ashok

Final project results for autonomous quadrotor navigation in randomized 3D MuJoCo environments.

Project Overview

This project studies autonomous drone pathing in a cluttered 3D MuJoCo environment. The robot is a Skydio X2-style quadrotor controlled through high-level velocity and yaw-rate commands rather than direct rotor thrust. Each rollout randomizes the start state, target location, and obstacle layout, so the policy must learn both target-seeking and local obstacle avoidance.

The final experiments compare on-policy PPO, off-policy SAC, and two PPO-based modifications. The first modification strengthens goal arrival and stabilization behavior, while the second trains with wind disturbances to test robustness under external forces.

  • Simulator: MuJoCo
  • Platform: Skydio X2-style quadrotor
  • Observation: drone state, target vector, and multi-beam lidar
  • Evaluation: mean return, success rate, final distance, collisions, and rollout videos

Environment and Reward

The task rewards progress toward the target and successful arrival, while penalizing collisions, unsafe flight, excessive speed, abrupt actions, and inefficient control. Obstacle-aware terms use lidar and geometric clearance signals so the drone learns to avoid narrow or unsafe paths rather than only flying directly toward the goal.

  • Randomized target positions and obstacle layouts
  • Capsule obstacles distributed across a bounded 3D workspace
  • Low-level proportional controller maps policy commands to rotor thrust
  • Final report assets live in RL_Final_Report/
